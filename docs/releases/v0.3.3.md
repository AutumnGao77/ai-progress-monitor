# v0.3.3 版本说明

本版本集中修复桌面会话状态识别和重复提醒。正式发布状态、源码提交、附件与校验和以 [GitHub Release](https://github.com/AutumnGao77/ai-progress-monitor/releases/latest) 为准。

## 修复内容

| 场景 | 修复后的行为 |
|---|---|
| ChatGPT 在继续工作时提出异步问题 | 显示待处理；问题逐条匹配答案，工具调用成功不再被误判为已回答 |
| ChatGPT 长会话、重复会话文件与延迟完成事件 | 分批重放必要生命周期；保持稳定的完成时间；空白回复和设置变化不产生新结果提醒 |
| ChatGPT 运行中的会话暂时不再写入日志 | 同一桌面进程存活时保留已观察到的运行状态；明确结束或进程退出仍会收口 |
| 打开或重命名旧 ChatGPT 窗口 | 窗口标题仅用于导航，不创建虚假的新任务气泡 |
| Qoder CN 0.4.8 | 读取新版会话数据库和 SDK 日志；兼容旧版入口，避免继承旧数据中的额度阻塞状态 |
| 系统进程较多 | 在昂贵查询前筛选候选进程，减少扫描超时风险 |
| 已查看结果的数据源短暂消失后恢复 | 在当前 Pet 进程内保留有界已读记录，不重新提醒同一结果；新结果及真实待输入仍正常提醒 |
| 单条 SDK 日志过长 | 有界地继续读取，不阻塞后续生命周期更新 |

状态变化诊断仅记录哈希会话标识、状态和结果时间，不记录标题、问题、答案或会话正文。发布文本扫描排除栅格图片的 Base64 编码，保留周边文字与 SVG 内容检查。

## 下载包与适用范围

- macOS：`AI-Progress-Monitor-v0.3.3-macOS-arm64.zip`，适用于 macOS 13+、Apple silicon，需安装 Python 3.9+。
- 便携包：`ai-progress-monitor-v0.3.3-portable.zip`，用于 Web/CLI 集成、诊断和 Windows 轻量预览。
- macOS App 沿用 ad-hoc 签名，未经过 Apple 公证；Windows 仍为预览，不宣称完成 Windows 实机验收。

系统通知、外观、隐藏和退出的操作方式保持不变。通知开关保留用户原设置。
