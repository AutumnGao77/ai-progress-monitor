# v0.3.5 版本说明

此版本修复了 WorkBuddy 和 Qoder 桌面会话的状态误报。

| 场景 | 修复后的表现 |
| --- | --- |
| WorkBuddy 原生命令审批 | Pet 显示待处理。仅查看气泡不会清除审批。 |
| Qoder / Qoder CN 等待用户选择或批准命令 | 按当前会话的等待和恢复记录更新气泡。 |
| WorkBuddy、Qoder 长时间没有新消息 | 当前应用进程内仍在执行的任务保留具体会话。 |
| 有明确额度不足记录 | 保留用户需要处理的状态。Qoder 同一轮随后的取消记录不会清除额度提示。 |
| 独立 Qoder IDE 进程 | 打开 IDE 不会生成虚假的 Qoder CLI 任务。 |

macOS 13 及以上的 Apple silicon 用户下载 macOS arm64 包。便携包包含 Web / CLI 集成和 Windows 预览。macOS 应用使用 ad-hoc 签名，运行环境需提供 Python 3.9 或以上版本。
