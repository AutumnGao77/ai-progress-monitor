# v0.3.4 版本说明

本版本修复重复空闲气泡和空闲对话无法收口的问题，并修复 macOS 原生窗口可能因日志写入异常而退出的问题。

| 场景 | 修复后的行为 |
| --- | --- |
| Qoder / Qoder CN 刚启动就出现多个气泡 | 搜索、知识库和插件辅助服务不再被当成独立桌面入口 |
| WorkBuddy 出现重复空闲气泡 | 预热进程不生成额外入口 |
| 多个进程属于同一 AI 工具 | 同产品的通用空闲入口合并为一个；Qoder 与 Qoder CN 分开 |
| 桌面或 CLI 对话长时间空闲 | 所有工具（包括 ChatGPT、Claude、Codex）统一在空闲满 15 分钟后移出具体对话；工具仍运行时保留一个入口 |
| CLI 持续扫描但没有新活动 | 扫描心跳不重置空闲计时；新活动恢复具体会话，进程退出移除入口 |
| 点击已经收起的工具入口 | 正常返回工具，不重新展开过期对话 |
| 日志文件关闭、不可写或并发关闭 | 日志安全降级，不因此终止 macOS 原生窗口 |

运行中、真正等待用户操作的会话不按空闲规则回收。已查看的结果从查看时计时；其他明确空闲事件使用来源时间；只有进程活跃度的 CLI 使用连续观察到的空闲时长。所有规则只影响气泡，不结束 AI 工具进程。
