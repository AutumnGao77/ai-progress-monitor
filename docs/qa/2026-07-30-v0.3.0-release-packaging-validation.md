## 候选阻断缺陷与修复

| 项目 | 记录 |
|---|---|
| 发现方式 | 首次构建成功后，从新临时目录解压 portable ZIP，并运行包内 `scripts/e2e_smoke.py` |
| 失败现象 | `smoke-inline` 未进入 `/api/sessions`，E2E 报 `needs_action session not found` |
| 根因 | portable 包不包含 `src/`，但 `monitor_command.py` 与 `doctor.py` 只把不存在的 `portable/src` 加入导入路径，无法导入 pyz 内的 `ai_progress_monitor` |
| 构建门禁盲点 | 旧构建只用仓库源码版 `scripts/e2e_smoke.py` 验证 `dist/ai-progress-monitor.pyz`，没有运行 portable 包自带脚本 |
| 修复 | 开发态优先导入 `src/`；portable 解压态回退同级 `ai-progress-monitor.pyz`；构建后强制运行包内 `monitor_command.py --help`、`doctor.py --help` 与包内 E2E |
| 测试证据 | 3 个新增测试先因缺少能力失败，修复后相关 43 项、本地全量 517 项及本地发布校验全部通过 |
| 候选处理 | 首次 ZIP 和 SHA-256 作废；必须重新构建、重新解压、重新验包和重新计算哈希 |

## 最终验收发现的阻断缺陷与撤回
